# e2e (top-level)

## Purpose
Top-level end-to-end test assets that live outside the `playground/` package. Currently contains a single generated output directory `__liberty-raster__` holding pixel-match survey PNG/JSON output for the Liberty raster overlay scenario. This directory is structurally equivalent to the per-scenario output directories inside `playground/e2e/__*__/` but is placed at the repo root because the corresponding spec runs against a different server configuration. The contents are generated data — not source code — and are regenerated by the relevant pixel-match survey spec run.

## For AI Agents

### Working In This Directory
- This directory contains only generated output. Do not write source code here.
- The `__liberty-raster__/` directory is regenerated by running the relevant pixel-match spec (see `playground/e2e/_pixel-match-survey.spec.ts` or the liberty-raster variant).
- To update baselines: run the spec with `-- --update-snapshots` from the `playground/` directory.
- If you need to add new top-level e2e assets (non-playground server configs), create a new subdirectory and document it here.

### Testing Requirements
- No runnable tests live directly in this directory. Tests that produce output here are located in `playground/e2e/`.

### Common Patterns
- Generated survey directories follow the naming convention `__<scenario-name>__/` and contain `xgis.png`, `maplibre.png`, and `buckets.json`.

## Dependencies
